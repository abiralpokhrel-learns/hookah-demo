# ORIGINAL Hookah (joke) — 100% real, trust me bro

Totally ORIGINAL browser hookah demo (joke). Tobacco-free visual demo. 18+.
All on-device with MediaPipe.

Live demo: hosted with GitHub Pages (see repo Settings > Pages after push).

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000 in Chrome/Edge
```

> Don't open via double-click (`file://`) — browsers block the camera + modules that way.

## How to use
1. Confirm 18+ & start front camera
2. **Grab (joke):** close a **FIST** inside the dashed ring
3. **Inhale (joke):** bring fist **TO your mouth**, mouth closed
4. **Blow (joke):** pull fist **AWAY** + open mouth wide
5. **Rings:** perfect **O** lips = rings, puffed cheeks = big cloud
6. Fallback: hold **SPACE** to inhale, **R** for ring

## Tech
Built from scratch with MediaPipe Tasks Vision (`@mediapipe/tasks-vision`) via CDN (jsdelivr → unpkg fallback). No build step — static HTML/CSS/JS.
